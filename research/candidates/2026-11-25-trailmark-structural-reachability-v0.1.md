## Observed, inferred, unknown

**Observed in retrieved source:** the laboratory schedules queue, STOP, effective STOP, commit, restart and retry events; configuration controls fences, bypass, durability, cancellation and essential service; the oracle evaluates a simulated journal. The source and expected outcomes are machine-authored. The README stipulates request-time policy and insertion-order semantics for same-tick events.

**Inference / candidate:** the same static graph may be compatible with materially different temporal outcomes because configuration and event ordering differ. This is a limit of graph-only inference, not a demonstrated Trailmark defect. Graph inspection may help locate commit sinks and possible alternate paths, but semantic feasibility, authority binding and actual denial require additional evidence.

**Unknown:** exact Trailmark v0.9.0 extraction coverage for nested Python functions, dynamic dispatch, external links and the laboratory's control structures; false positives/negatives; dependency integrity; comparative value over manual or other static analysis; external-system completeness; legal or institutional standing of any authority; independent reviewer disposition.

Each edge must distinguish tool-extracted, manually declared, inferred and runtime-observed provenance. Unknown is not absent. A graph does not confer permission, and a test result cannot admit itself.
