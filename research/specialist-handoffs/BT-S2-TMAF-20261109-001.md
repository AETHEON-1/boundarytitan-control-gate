## Research question
Can an auditor independently falsify false assumptions in a supplied threat model while respecting legitimate scope constraints, without laundering the model's assertions into verified security conclusions?

## Experiment contract
Before each run, a human specialist freezes: specimen commit/digest, model bytes/digest, scanner version/configuration, actual deployed topology, seeded ground truth, allowed tools, network isolation, exact prompt, execution authority, and independent effect oracle. Randomize/blind model variants where feasible. Run matched conditions (A) no model, (B) correct model, (C) deliberately flawed model. Keep outputs, errors, raw transcripts, and negative results. Do not score an authorized out-of-scope exclusion as a vulnerability detection failure unless the auditor falsely claims coverage or safety.

## Measurement and disposition
Define TP/FP/TN/FN against a precommitted per-surface ground-truth set. Report detection recall = TP/(TP+FN) and precision = TP/(TP+FP), with undefined denominators marked N/A. Separate finding-level from surface-level counts, ambiguous cases, legitimate exclusions, and incomplete runs. Compare matched runs and provide uncertainty; no numeric thresholds or effect sizes are asserted in advance.

Per case return: `FAILURE OBSERVED`, `NO FAILURE OBSERVED`, `INDETERMINATE`, `TEST INVALID`, or `NOT TESTED`. Each includes exact reproducibility recipe, independent reviewer identity, raw artifact locators and hashes, observation-vs-inference separation, competing explanations, false negatives, residual consequence, and remediation candidate. Passing a bounded test is not universal assurance.
