# Constraint Precedes Capability Doctrine v0.1

## Doctrine

Capability is not admitted because it exists. It is admitted for bounded review only after its constraint envelope is explicit.

`Constraint → Evidence → Owner → Stop → Revocation → Harm Window → Scope → Capability`

## Required constraint envelope

- Capability definition
- Allowed scope
- Forbidden actions
- Evidence custody
- Constraint owner
- Consequence owner
- External stop path
- Revocation path
- Independent measurement
- Harm window
- Uncertainty register

## Disposition

- `CAPABILITY_ADMITTED_FOR_BOUNDED_REVIEW` — constraints are supplied; external decision remains required.
- `CAPABILITY_HELD_FOR_CONSTRAINT_REPAIR` — capability exists, but the envelope is incomplete.
- `NOT_ADMISSIBLE` — the capability itself is not sufficiently defined.

This doctrine does not grant authority, approve deployment, certify safety, or allow the machine to close its own review.
