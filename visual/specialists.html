1. Understand the boundary

CAN ⊬ MAY. A system's ability to produce an output or perform an action does not, by itself, establish permission or authority to impose a consequence.

BoundaryTitan tests transitions between capability, permission, action, consequence, evidence and human decision. It does not claim that every proposed control is necessary, sufficient or independently verified.

3. Reproduce the software baseline

Requirements: Git, Node.js and npm compatible with the repository lockfile, and Python 3. The commands below are read-only verification of a local checkout after dependency installation; they do not operate hardware.

git clone https://github.com/AETHEON-1/boundarytitan-control-gate.git
cd boundarytitan-control-gate
npm ci
npm run typecheck
npm test -- --coverage=false
npm run test:python
npm run verify:state

Pin a commit SHA before claiming reproduction. CI is evidence for the tested commit only. The repository's latest GitHub Actions history is the live source for run status; this static page makes no live-status claim.

Contribution guidance · Pull requests

Suggested minimum submission: claim ID, reproduction steps, expected versus observed behavior, source/version, counterevidence, and what result would change your conclusion. Do not include secrets, personal data or unsafe live-system instructions.
