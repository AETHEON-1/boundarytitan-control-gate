# Review Surface — Human Translation Key

This page is a dashboard for looking, not a console for acting.

- **What is proposed?** The bounded work being brought to review.
- **What could change?** The stated consequence; not a prediction of safety.
- **Who owns it?** The humans responsible for the consequence and decision.
- **What evidence supports it?** Sources, freshness, and custody—not proof by themselves.
- **What is uncertain?** Questions that remain open.
- **What does this rely on?** Declared dependency context; it may honestly say none are declared or that context is unknown.
- **What changed underneath it?** Reinspection candidates created from observed dependency changes.
- **Who can stop it?** The owner of the external stop path and revocation authority.
- **Who can still say no?** The visible refusal path before consequence.

Green means the packet is ready to be read by a human. It does not mean the machine said yes.
