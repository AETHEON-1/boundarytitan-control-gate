# Security policy

BoundaryTitan is a read-only preparation and review prototype. It does not
grant permission, control live credentials, authorize execution, certify
safety, or close human review.

## Reporting

Please report suspected vulnerabilities or boundary failures privately to the
repository owner before opening a public issue. Include the affected file or
workflow, reproduction steps, consequence surface, and whether the issue can
bypass an owner, stop path, revocation path, or evidence boundary.

Do not include secrets, personal data, or live credentials in reports.

Security reports are evidence for human review. A report, test result, or fix
does not itself authorize deployment or establish certification.
