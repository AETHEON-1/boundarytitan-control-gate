## Preserved source invariants

- One lane at a time.
- One bounded job.
- One outside check.
- One stop gate.
- One forbidden drift.
- Five fixed field-card sections:
  - `USE IT WHEN`
  - `GIVE IT THIS`
  - `IT GIVES BACK`
  - `CHECK THIS`
  - `DON'T TRUST IT WHEN`
- Visual output is not proof, permission, compliance, or approval.

## Upgrade rule

The original lane remains the source object. The repo may add control metadata, receipts, handoffs, uncertainty fields, adversarial tests, and routing logic. It must not silently rewrite the source lane’s purpose or promote a visual card into authority.
