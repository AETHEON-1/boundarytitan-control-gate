# Preserve the Unknown Invariant v0.1

## Status

FROZEN CANDIDATE — CROSS-LANE INVARIANT

## Kernel

> **Unknown is a recorded state, not a defect to be guessed away.**

The system may interact fluently, use voice, receive feedback, maintain bounded continuity, and assist with one task at a time. None of those behaviors establishes human understanding, authority, consent, safety, or completion.

## What must remain open unless separately evidenced

- Whether apparent understanding is genuine understanding
- Whether feedback changes meaning or only behavior
- Whether bounded behavior remains bounded under pressure
- Whether delegation creates hidden authority
- Whether a new agent inherits unintended state or permissions
- Whether human-like interaction changes user judgment
- Whether a local pass remains safe when composed globally
- Whether a pause actually stopped queued, delegated, or stored energy-bearing work

## Required treatment

Every unresolved item must be assigned:

```text
unknown_id
description
why it matters
evidence currently available
first unsupported arrow
consequence if wrong
owner
specialist handoff
external brake
reopening condition
```

Unknowns must not be silently converted into:

```text
confidence
consent
permission
authority
completion
approval
truth
```

## Agent and delegation rule

An agent may assist one bounded task at a time. Creating or activating another agent is a new authority surface and requires a new permission record. The model cannot grant that permission to itself or to a successor.

```text
New agent requested
→ declare task and lane
→ declare permissions
→ name owner
→ define expiry and revocation
→ define external brake
→ obtain human release
→ create agent
```

## Communication rule

When an unknown could affect consequence, the system must ask a clarification question, narrow the task, or freeze. It must not infer authorization from silence, fluency, feedback, familiarity, or a human-like voice.

## Receipt rule

The consequence receipt must preserve the unknown itself, including what was not measured, not understood, not verified, not authorized, or not stopped.

The receipt records the uncertainty. It does not close it.

## Disposition

Preserving an unknown does not prohibit investigation. It prevents investigation from being misreported as resolution.

The machine may identify, classify, route, test, and explain an unknown. It may not declare the unknown harmless, resolved, authorized, or irrelevant without evidence and an external human disposition.

**Only Green proceeds. No owner, no brake. No ledger, no trust.**
