# Current Work Integration Map

**Record date:** 2026-08-20

**State:** DRAFT INTEGRATION MAP — descriptive; no authority granted

## Purpose

Make current BoundaryTitan work inspectable without collapsing historical doctrine, implemented structure, proposed controls, or human decisions into one status claim.

## Four-part map

| Layer | Status | Repository treatment |
| --- | --- | --- |
| RC1 architecture baseline | Frozen historical input | Preserve unchanged; do not reformat, move, rename, or silently amend. |
| Phase 1 contracts | Merged declaration-only baseline | Type declarations, fixtures, and compatibility tests only; no runtime authority. |
| Phase 2 proposal routing | Separate draft branch | Pure, deterministic structural routing; not merged by this record. |
| Current-work architecture | Proposed integration | Derived from Boundary Atlas and live-publication review; no runtime implementation or authority. |

## Claim taxonomy

| Claim class | Meaning | Permitted use |
| --- | --- | --- |
| Documented source | Traceable external legal, technical, or governance material | Cite source and scope. |
| BoundaryTitan doctrine | Publicly stated project rule | Preserve as doctrine; do not present as external law. |
| Structural synthesis | Interpretation connecting sources and doctrine | Label as synthesis, with premises visible. |
| Bounded inference | Limited conclusion from stated evidence | Preserve limit, assumptions, and reopening condition. |
| Rhetoric | Explanatory framing | Never use as independent authority. |

## Required separation

- Evidence may support a finding; it does not issue `MAY`.
- A routing color is not approval, permission, release, or execution.
- Passing tests are structural evidence only.
- A repository state record may describe work; it may not close, certify, publish, deploy, or authorize it.
- Human authority and an external stop path remain outside machine output.

## Phase 2 boundary

The `phase2-rule-engine` branch is limited to deterministic evaluation of declared proposal shapes and returns findings plus a route. It does not implement the future-control backlog, issue decisions, grant permission, release a token, execute an external action, write an audit ledger, or operate a stop path.

Any review, merge, release, or future-phase authorization remains a human-owner decision. This map itself has no consequential effect.
