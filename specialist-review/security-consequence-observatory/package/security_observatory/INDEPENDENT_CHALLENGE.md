# Independent methodological challenge (adversarial desk review, not independent human review)

## Blocking findings
1. **Snapshot coverage**: an arbitrary partial ZIP or directory can be treated as complete. The importer marks absent months as zero. Until source completeness is independently checked against official release manifest and expected archive structure, output must NOT be treated as a full historical series.
2. **Retrospective revisions**: a current CVE snapshot is not the contemporaneous historical publication view; late records and date corrections alter past counts. Preserve immutable source snapshots and timestamps.
3. **KEV date semantics**: dateAdded is the date CISA added an entry, not the exploit date. Historical additions can reflect old CVEs.
4. **Population mismatch**: ITRC US data compromises are not equivalent to global exploitation or CVE events; cross-series ratios do not estimate exploit or breach probability.
5. **Remediation**: no monthly denominator, observation frame, or independent denial-test receipts; annual vendor survey metrics cannot be interpolated monthly.
6. **Path closure**: patch success and revoked credentials cannot establish that every consequence path is unreachable. No verified closure population is available.
7. **Future-month bug risk**: month-first comparison includes October 2026 even though only 29 days have elapsed; month must be marked PARTIAL.
8. **Input integrity**: source SHA-256 only for ZIP/CSV; directory source needs a canonical file manifest and checksums.
